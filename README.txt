শপিং স্মার্ট দর্শনা — ফ্রি ওয়েবসাইট

ফাইল:
- index.html = মূল ওয়েবসাইট
- logo.png = লোগো

ফ্রি প্রকাশ:
1. GitHub-এ একটি account খুলুন।
2. New repository তৈরি করুন।
3. index.html ও logo.png upload করুন।
4. Settings → Pages → Deploy from branch নির্বাচন করুন।
5. Branch হিসেবে main এবং folder হিসেবে /root নির্বাচন করে Save দিন।
6. কিছুক্ষণ পর আপনার ফ্রি website link তৈরি হবে।

ফোন নম্বর ও পণ্যের তথ্য index.html-এর লেখা পরিবর্তন করে নিজের তথ্য দিন।
